# АвтоДозор — мобильное приложение (React Native / Expo)

Приложение сотрудника ГИБДД по ТЗ: вход по токену, личный кабинет, «Мой розыск», «База розыска», карта камер,
оповещения в реальном времени (WebSocket), история оповещений с экспортом в Word/Excel.
Работает с готовым backend (FastAPI + MySQL): `/api/...` по HTTP, оповещения по `ws://.../ws/{id}?token=...`.

## Запуск

1. Запустите backend (из папки `backend`, как в его README) и сервис камер — без него оповещений не будет.
   Backend должен слушать `--host 0.0.0.0`.
2. В папке проекта:
   ```bash
   npm install
   npx expo install --fix      # подгонит версии пакетов под вашу версию Expo
   npx expo run:android        # соберёт и запустит на эмуляторе Android Studio / телефоне по USB
   ```
   Эмулятор должен быть запущен заранее (Device Manager в Android Studio → ▶).
3. На экране входа внизу нажмите «Сервер» и проверьте адрес:
   - эмулятор: `http://10.0.2.2:8000` (по умолчанию);
   - реальный телефон: `http://<IP-компьютера в Wi-Fi>:8000`, телефон и компьютер в одной сети.

Альтернатива без сборки: `npx expo start --go` и открыть QR-код в Expo Go (нужна версия Expo Go, совпадающая с SDK).

## Настройки (`src/config.js`)
- `DEFAULT_SERVER` — адрес backend по умолчанию;
- `FOLLOWUP_SECONDS` — интервал повторного оповещения «результат розыска» (по умолчанию 60 с);

## Карта
Карта — это картинки из вашей папки `public`: `All_map.jpg` (все камеры) и `cam_1.jpg`…`cam_15.jpg` (камера выделена красным). Интернет для карты не нужен. Номер камеры берётся из цифр её кода (`CAM-08` → 8), для камер с номерами 1–15 есть картинки.
